4. 技术实现要点

后端 server.js

  • 增强现有 POST /api/chat 端点
  • 添加工具调用循环（search_jobs/list_skills/list_companies/get_job_detail）
  • 动态系统提示词（网页功能介绍+数据统计+领域边界）
  • SSE 流式返回（打字机效果）
  • ChatPanel 不暴露 trigger_crawl（功能3暂不做）
  • 外部链接抓取：Node.js fetch + cheerio 解析（轻量，不需要 Playwright）

前端 ChatPanel.vue

  • 新组件，自包含，App.vue 只改 2 行
  • 消息列表 + 输入框 + SSE 流式解析
  • 设置面板侧边栏新增 "🤖 求职助手" tab
  • JobModal 底部加 "🧠 分析学习路线" 按钮
  • 连接状态指示器（绿点=已连接 / 灰点=未连接）
  • 错误处理：无后端/限流/未配置API Key

部署策略

  • 聊天 API（server.js 的 chat 部分）部署到国内可访问的轻量服务器
  • 选项：阿里云函数计算 / 腾讯云云函数（按调用量计费，几乎免费）
  • 生产环境自动检测后端连接状态
  • 后端不可用时聊天面板显示"请启动服务器"提示

5. 数据流

用户输入 → ChatPanel fetch('/api/chat') → server.js → DeepSeek API → SSE 流式返回
工具调用时： DeepSeek → 返回 tool_calls → server 执行工具 → 结果塞回 DeepSeek
