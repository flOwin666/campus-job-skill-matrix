现实梳理：哪些功能不需要后端，哪些需要

功能 需要后端？ 依赖大小 普通用户能用？
浏览岗位矩阵/列表 不需要 0 能（GitHub Pages）
搜索/筛选岗位 不需要 0 能（纯前端）
技能管理（三色） 不需要 0 能（纯前端）
功能1：AI网页问答 需要 仅 npm 包 需要后端部署
功能2：AI学习路线 需要 仅 npm 包 需要后端部署
功能3：AI触发爬虫 需要 Playwright + Chromium
~500MB+ 		需要独立服务器

关键洞察：功能1+2 和 功能3 的依赖完全不同

🔌 功能 1 + 2 = 轻量 LLM 代理
只需：
  • Node.js + ~10 个 npm 包
  • DeepSeek API Key
  • 读取 JSON 文件
  • 不需要 Playwright

可以部署到任何 Node.js 服务器
甚至 Vercel Serverless 也行

🕷️ 功能 3 = 重型爬虫引擎
必须：
  • Playwright + Chromium (~500MB)
  • 真实浏览器环境
  • 可能需要代理池
  • 不适合 Serverless

必须部署到有完整 Chromium 的服务器
（阿里云/腾讯云等，最低 2GB 内存）

三种部署方案

方案 描述 聊天Q&A 学习路线 爬虫 月费
A. 轻量 仅聊天 API 部署到 Vercel（或用 Cloudflare Workers 绕过封锁）。爬虫功能需要本地 server。 ✅ ✅ 本地 免费
B. 全功能 server.js 全部功能部署到一台阿里云/腾讯云服务器。用户零安装。 ✅ ✅ ✅ ~30元
C. 本地 保持现状，聊天和爬虫需要本地运行 node server.js。前端展示聊天按钮但显示"未连接服务器"。 本地 本地 本地 免费

推荐先走方案 A（轻量分离）

先把功能1+2的 chat API 部署到一个免费/便宜的 Node.js 服务器，让所有用户都能用 AI 聊天。功能3（爬虫触发）标记为"需要本地服务器"或在聊天里告诉用户"当前未连接爬虫引擎"。等将来需要时再升级到方案 B。

注意：Vercel 仍然被墙。但可以换 Cloudflare Workers 免费方案，国内访问基本正常。
