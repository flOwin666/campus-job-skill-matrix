一、作品简介

校招岗位技能矩阵是一款面向 AI/算法方向校招求职者的智能辅助平台，将多源岗位数据聚合、技能图谱可视化、AI 对话分析三大能力融为一体。学生用自然语言提问即可搜索岗位、分析 JD、查询技能、生成学习路线，告别在海量招聘信息中盲目翻找的低效状态。

产品核心逻辑是"让 AI 替你搜、帮你分析、给你路线图"——底层自动抓取五家主流互联网企业的校招技术岗位，中台通过 7 个 Function Calling 工具将大模型与岗位数据库和技能知识库打通，前端以矩阵视图、对话面板、交互式思维导图三种形式呈现结果。目前已通过 Vercel + GitHub Pages 完成双端部署上线，可供真实用户访问使用。

二、市场调研

当前校招市场存在三个突出痛点：

  1. 信息碎片化：学生需要在各公司招聘官网、Boss 直聘、拉勾、牛客等多个平台之间来回切换，同一岗位在不同平台信息不一致，缺少统一的岗位数据聚合工具。
  2. JD 理解门槛高：AI 方向校招 JD 常包含大量技术名词（RAG、LoRA、RLHF、vLLM、TensorRT 等），非顶尖院校学生缺乏对这些技能的系统认知，无法有效评估自身匹配度。
  3. 学习路径不清晰：市面上的面经和学习建议多为碎片化的博客文章，缺乏"针对这个具体岗位，我应该先学什么、再学什么、做什么项目"的结构化指导。

现有竞品分析：牛客、LeetCode 侧重刷题和面经，BOSS 直聘侧重岗位搜索和投递，ChatGPT 等通用 AI 工具虽然能回答求职问题但无法直接查询真实岗位数据。本作品填补了"AI 求职助手 + 实时岗位数据库 + 结构化学习路线生成"这一空白，是目前唯一将三者整合的产品。

三、方案介绍

整体方案分为三层：

数据层：通过模块化爬虫引擎自动抓取百度、字节跳动、阿里巴巴、腾讯、美团五家企业的校招技术岗位，使用 Playwright 真实浏览器渲染 + 反检测策略获取详情页完整 JD。技能提取采用分段解析（职位描述 / 职位要求 / 加分项各自独立提取），去重逻辑基于"公司 + 标题 + 城市 + URL ID"四元组防止不同岗位被误合并。数据输出为标准 JSON 格式，同时托管在 GitHub 仓库供前端动态加载。

AI 层：采用 DeepSeek API（deepseek-v4-flash 模型），通过 Function Calling 机制让大模型获得"动手能力"——定义 7 个工具函数，LLM 根据用户意图自主决定调用哪个工具。后端集成 75 项技能知识库（每项含分类、难度、前置知识、描述），工具执行器支持递归解析前置技能链。关键创新在于"服务器端拦截"机制：当工具返回岗位列表或学习路线等长内容时，后端直接格式化并通过 SSE 推送给用户，绕过 LLM，杜绝其"总结概括"倾向。

展示层：Vue 3 + Vite 构建 SPA 前端，包含矩阵视图（技能 × 岗位二维表格）、列表视图、岗位详情弹窗、AI 对话面板（SSE 流式渲染 + Markdown）、交互式思维导图（SVG 拖拽 + 碰撞检测 + 双击新建 + 本地持久化）。支持三端部署：开发环境本地 Express 后端、生产环境 Vercel Serverless 函数、Obsidian 本地笔记同步。

4.2 创新点

  1. "工具调用 + 服务器端拦截"双保险架构：常规 AI 工具依赖大模型直接生成回答，存在幻觉和偷懒问题。本作品为 LLM 配备 7 个 Function Calling 工具直连真实岗位数据库，并独创服务器端结果拦截——岗位列表、学习路线等核心内容由服务器直接格式化推送，绕开 LLM，从根本上杜绝信息失真和内容缩水。这与常见的"写好 Prompt 祈祷 LLM 好好回答"的做法有本质区别。
  2. 技能知识图谱驱动学习规划：自建 75 项技能知识库，标注分类、难度和前置依赖关系。系统递归解析前置技能链，自动生成包含前置知识、分阶段学习、推荐资源、项目练习的结构化路线，而非泛泛的"建议你学一下 Python"。
  3. 交互式思维导图 + 本地持久化：将枯燥的技能列表转化为可拖拽、可编辑、可保存的 SVG 知识图谱，支持碰撞物理检测、双击新建分支、右键菜单操作、导图库管理，实现技能体系的"可视化学习规划"。

5.2 AI 能力方案

模型选型：选用 DeepSeek v4-flash，原因是其 Function Calling 能力稳定、中文理解优秀、API 价格低廉（每百万 token 约 1 元人民币），适合学生用户场景。同时保留兼容 OpenAI 格式的接口设计，可无缝切换至通义千问、Kimi 等其他模型。

工具调用链：每次对话请求构建包含 4 段内容的动态 System Prompt（角色定位 → 数据概况 → 技能知识摘要 → 回答规范与 Few-shot 示例），LLM 根据 5 类 Few-shot 示例自主判断何时调用哪个工具。工具执行循环最多 5 轮，每轮支持 LLM 继续调用工具或输出最终文本回复。

流式输出：采用 SSE（Server-Sent Events）协议，LLM 逐 token 推送，前端 ReadableStream 逐行解析，支持工具进度动画（tool_start / tool_result 事件）。

对话记忆：以 IP 为 key 维护最近 3 轮对话摘要（每条截断 300 字），拼入 System Prompt 后方供 LLM 理解上下文和指代关系。

隐藏消息过滤：前端自动发送的操作指令（如 "分析学习路线" 按钮触发的 prompt）标记为 hidden，发送前过滤，防止污染 LLM 对话上下文。

数据流向：用户提问 → 消息清洗 → 拼接 System Prompt + 记忆 + 历史 → 发送 DeepSeek（带 7 tools + stream）→ LLM 返回 tool_calls → 后端执行工具 → 关键结果拦截直接推送用户 → 工具结果回填 → LLM 继续或输出最终回复。

八、落地规划（落地性说明）

当前状态（已完成）：产品已完成从数据采集到 AI 对话到前端展示到生产部署的全链路闭环。开发环境和生产环境均已可用，生产环境通过 Vercel Serverless 函数 + GitHub Pages 运行，无需服务器成本。爬虫引擎支持 5 家公司岗位数据的全量抓取和增量修复。

短期规划（1-3 个月）：

  • 接入更多企业数据源（网易、小米、京东、小红书等），将覆盖范围从 5 家扩展到 10+ 家
  • 完善技能知识库，每条技能描述从当前 1 句话扩充到 200-300 字的详细说明
  • 补充 get_job_detail、get_skill_info、list_skills 三个工具的服务器端拦截
  • 增加用户技能画像功能（学生设置自己已掌握的技能和水平），AI 据此给出个性化匹配度评估
  • Vercel 升级至 Pro 套餐解决 Hobby 10s 超时限制，或迁移至国内云服务器

中期规划（3-6 个月）：

  • 引入 RAG（检索增强生成）替代当前 System Prompt 内嵌知识的方式，技能详细文档存入向量数据库按需检索
  • 增加简历优化功能：学生上传简历 → AI 提取技能 → 对比目标岗位 JD → 给出修改建议
  • 增加模拟面试功能：基于岗位 JD 生成面试题，AI 扮演面试官进行对话练习
  • 用户系统：支持注册登录，持久化对话历史、学习进度、思维导图收藏

长期愿景（6-12 个月）：打通"岗位发现 → 技能评估 → 学习规划 → 简历优化 → 模拟面试 → 投递跟踪"的求职全流程闭环，成为 AI 方向校招求职者的首选一站式平台。

九、商业化思考

目标用户：全国 AI/算法方向校招求职者，当前覆盖 5 家公司，可扩展到全行业技术岗位。首批核心用户为双一流高校计算机/AI 相关专业学生。

商业模式：

  1. 基础免费 + 高级付费（Freemium）：基础岗位搜索、AI 对话、学习路线生成免费使用。高级功能（深度技能匹配分析、无限次详细学习路线、AI 模拟面试、简历优化）按月或按年订阅，目标定价 19-29 元/月。
  2. 企业端服务（B2B）：为企业提供校招岗位的候选人匹配服务——基于学生技能画像与岗位 JD 的 AI 匹配评分，帮助企业更精准地找到合适候选人，按成功入职收费。
  3. 教育机构合作：与培训机构、高校就业指导中心合作，提供定制化的技能评估和学习路线规划工具，收取 SaaS 服务费。
  4. 广告与推广：在不影响用户体验的前提下，为培训机构、在线课程平台提供精准的技能学习资源推荐。

成本结构：当前运营成本极低——Vercel Hobby 免费套餐 + GitHub Pages 免费托管 + DeepSeek API 按量计费（每百万 token 约 1 元）。即使日活 1000 用户，月 API 费用预估不超过 500 元。主要成本来自后续可能的服务器迁移、向量数据库托管和团队人力。

竞争优势：相比通用 AI 对话工具（ChatGPT、Kimi 等），本产品有真实的岗位数据库和技能知识库作为壁垒；相比招聘平台（BOSS 直聘、牛客等），本产品有 AI 驱动的个性化分析和学习路线生成能力。定位在"AI 求职助手"这一垂直细分领域，避开与大厂的正面竞争。
